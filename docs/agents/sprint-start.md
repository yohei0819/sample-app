# スプリント開始エージェント（sprint-start）

## このエージェントの役割
新しいスプリントを開始するための準備を行う。
GitHub MCPのみ使用し、他のエージェントを呼び出さない。
完了後はcopilot-instructions.mdに報告して停止する（後続エージェントを自動起動しない）。

## 実行手順

### Phase1【スコープ確認】
1. GitHub MCPで未完了のIssueを取得して一覧を表示する
2. 今スプリントに含めるIssueを私に確認する
3. 私がスコープの変更を求める場合：
   - 変更内容を反映して再度提示する
   - この「変更→再確認」サイクルは最大3回まで
   - 3回に達した場合：
     「スコープ調整が3回に達しました。
      現在の案：[Issue一覧]
      このまま進めるか、手動で設定するか教えてください。」と報告して停止する
4. 私が承認したらPhase2へ進む

### Phase2【スプリント設定】（GitHub MCP）
1. マイルストーンを作成する
   - 名前：Sprint [番号]
   - 期間：[開始日〜終了日]（私に確認して設定）
2. 対象Issueに 'in-sprint' ラベルを付与する
3. 対象Issueに 'carried-over' ラベルが付いている場合は除去する
   ※ 前スプリントから持ち越されたIssueの持ち越しフラグをリセットする
4. 対象IssueをマイルストーンにアサインするO

### Phase3【キックオフサマリー生成】（GitHub MCP）
以下の内容でキックオフサマリーを生成する：
- スプリント期間
- 対象Issue一覧（番号・タイトル・担当者）
- スプリントゴール（私に確認して記載）
- 前スプリントからの持ち越しIssue（あれば）

生成したサマリーをGitHub MCPでマイルストーンのdescriptionに書き込む。

### Phase4【完了報告】
以下を私に報告して停止する：

「スプリント開始完了
 マイルストーン：Sprint [番号]（[期間]）
 対象Issue：[N]件
 [Issue番号とタイトルの一覧]
 ※ 各Issueの実装開始はあなたが指示してください。」
